# 정산 로컬 재현 결과와 서버 인계

계산 제품 코드의 변경 없이, PR #7 이후 수행한 B2·C1·C2 자료 검산과 서버 연결 규칙 분석을 공유한다. 실제 API·DB·배포 검증 완료를 의미하지 않는다.

## 재현

저장소 루트에서 실행한다. `PUBLIC_A_DIR`은 팀 공개 A05 PNG와 A06 텍스트를 풀어 둔 경로다. 비공개 검수 자료를 사용하지 않는다.

```sh
python docs/verify_b2_c1_c2.py --originals PUBLIC_A_DIR
python docs/audit_server_b1.py
python -m unittest discover -s app/reconcile -t . -p "test_*.py"
```

- `results.json`: B2·C1·C2 6개 사례의 전체 입력·출력과 출처 해시.
- `handoff.html`: 함수 호출 방식, 상태 요약, 서버에 필요한 정규화 입력과 남은 검증.
- `../../server-audit/B1_server_contract_audit.json`: 서버 소스 6개 사례의 현행/수정안 비교.
- `../../server-audit/B1_server_matching_proposal.patch`: 서버 담당자가 검토·적용할 수정안. 이번 브랜치는 서버 제품 파일을 변경하지 않는다.

## 확인 범위

| 단계 | 확인한 것 | 미검증 |
| --- | --- | --- |
| B2 | DL-A091 실제 판독·제공된 수령 확인 기록과 PR #6 DL-A131 판독값의 오프라인 조합. 현재 자료 그대로는 주간 수령·차이 null. A131 확인을 모의한 사례만 96kg·4kg·80,000원 | 같은 서버 기간에 속하는지, A131 실제 확인 이벤트, 실제 API 응답 |
| C1 | 제공 A06 문장과 수동 구조화한 40kg 주장, 모의 확인 이벤트. 기존 수령·청구 보존, 충돌·중복 메모 처리 | 실제 음성 전사·자연어 추출·점주 확인·DB 메모 저장 |
| C2 | 공개 A05 PNG를 시각 확인해 수동 전사한 수정 청구. 대체 미확인/대체만 확인 시 차단, 양측 합의 모의 시 승인 대상 1,920,000원·저장액 null | 실제 A05 OCR, 실제 대체·합의 이벤트, 승인 저장 |

`offline:`·`simulated:` ID와 `SIMULATED_OWNER`는 운영에 저장하면 안 된다. DL-A091의 실제 ID·확인 기록은 제공 JSON의 보고이며 이번 작업에서 배포 서버를 재조회하지 않았다. A05 수량은 스크립트의 수동 전사 값이며 실행 시 OCR로 재추출하지 않는다.

## 서버 담당에게 필요한 후속 작업

1. `app/workflow/settlement.py`의 `target()`에 납품일·규격 검증과 무번호 유일 후보 연결을 적용한다. 스냅샷 `settlement_5abcde45.py`는 검토 당시 main `8584d4494f9fc0a92ccecc3e21344410c5c1573a`의 해당 파일과 동일함을 확인했다. 고정 스냅샷 재현은 이후 배포 소스의 자동 검증이 아니다.
2. 현재 `ConfirmationRequest.kind`에 없는 `receipt_entry`와 직접 수령 입력의 저장·정산 연결을 확인한다.
3. 수정 청구의 대체 확인과 양측 수량 합의를 구분해 전달하는지 확인한다. 문구 존재와 실제 합의 확인의 관계를 점주 확인 흐름에서 검증한다.
4. 배포 Backend 커밋·DB 마이그레이션 버전, 독립 QA 기간 및 문서·행·거래 ID와 기존 실행 로그를 공유한다.
5. 수령 확인 전/후와 재전송, 메모 저장·재조회, 수정 청구, 승인·동시 요청·다른 세션 조회를 검증한다. 홍모 담당은 수량·금액·차단 사유를 검산한다.

서버 검증 스크립트는 main의 `tests/verify_public_a.py`에 이미 있다. 실제 서버에 기록을 남기는 스크립트이므로 본혁 담당의 QA 기간 준비 후 사용한다. 이 브랜치의 두 재현 스크립트는 네트워크·DB를 호출하지 않는다.

개인 실행계획 HTML, 환경 설정 변경, 공개 원본 바이너리는 이번 공유 범위에 포함하지 않았다. DL-A091 JSON은 이미 main에 있으므로 중복 추가하지 않았다.
