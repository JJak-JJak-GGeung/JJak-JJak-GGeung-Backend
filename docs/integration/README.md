# 우영의 통합 기록

배포한 Frontend·Backend 커밋과 실제 적용한 Database 마이그레이션 버전을 각각 기록한다. 각 PR에는 변경 경로, 실제로 사용한 입력, 결과와 확인 방법, 함께 적용할 다른 저장소 PR을 남긴다.

| 시각 | 웹 / 서버 / DB 버전 | 확인할 동작 | 실제 결과·ID | 통과 / 실패 / 미실행 |
| --- | --- | --- | --- | --- |
| 11:30 | | 실제 사진 업로드 → 거래 열기 → 명세·수령·청구 행과 각 원본 확인 | | |
| 12:30 | | 답변 확인 저장 → 수정 청구 대체 확인 → 재대조 → 점주 승인·승인본 열기 | | |
| 14:00 | | 다른 브라우저에서 같은 점주 로그인 → 승인 목록 → 처음 저장한 승인 ID·버전·금액·송금 상태 확인 | | |

15:30 제출 목표. 비공개 검수 입력·정답과 점주 로그인 정보는 우영이 별도 보관한다.
